# 会员奖励管理系统 (Allowance Rewards)

一个面向 Minecraft 服务器运营者的 **NeoForge 1.21.1** 服务端/客户端模组，提供完整的「玩家签到 + 奖励发放」管理方案：

- **玩家**：按 `K` 键或输入 `/allowance` 打开奖励中心，一键签到、浏览奖励卡片、领取奖品
- **管理员 (OP)**：输入 `/allowance admin` 打开管理面板，可视化创建/编辑/删除奖励包，直接在物品槽中放入任意模组物品
- **兼容性**：奖励物品以完整 ItemStack（含 NBT / 数据组件）序列化存储，天然兼容任意模组物品

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 每日签到 | 自动记录连续签到 / 累计签到天数，按自然日（服务器时区）判定 |
| 奖励包 | 27 格物品槽自由摆放奖励，支持任意模组物品与组件 |
| 领取方式 | 三种模式：`每日限领一次` / `签到后每日限领` / `签到后限领一次（永久）` |
| 启用/停用 | 一键停用奖励包，玩家端实时同步显示 |
| 安全 | 所有管理操作仅限权限等级 2（OP），客户端请求均在服务端二次校验 |
| 持久化 | 数据存于世界 SavedData（`data/allowance_rewards.dat`），重启、掉线不丢失 |
| 界面 | 中文可视化 GUI，支持滚动列表、物品悬浮预览、鼠标悬停提示 |

## 安装

1. 安装 [NeoForge 21.1.x](https://neoforged.net/)（服务端与客户端）
2. 将 `allowance-1.0.0.jar` 放入两侧的 `mods` 文件夹
3. 启动即可

> 服务端和客户端需要**同时安装**本模组（GUI 与网络同步均由模组提供）。

## 使用指南

### 玩家

- 按 **K**（可在按键设置中修改「会员奖励 → 打开奖励中心」）或输入 `/allowance` 打开奖励中心
- 点击「签到」完成今日签到，随后点击奖励卡片上的「领取」获得物品（自动放入背包，背包满时掉落地面）

### 管理员

- `/allowance admin` —— 打开管理面板
- `/allowance editor` —— 直接新建奖励包
- 管理面板中可：新建、编辑、删除（二次确认）、启用/停用奖励包
- 编辑器中：
  - 输入奖励包名称
  - 切换领取方式（每日限领 / 签到后每日限领 / 签到后限领一次）
  - 从背包或创造模式物品栏将奖励物品放入 3×9 物品槽
  - 点击「保存」生效；未保存关闭时物品自动退回背包

### 数据文件

- 位置：`<世界文件夹>/data/allowance_rewards.dat`
- 内容：全部奖励包定义 + 所有玩家的签到/领取记录
- 备份该文件即可完整迁移或回滚数据

## 仓库结构

每个发布版本对应一个独立文件夹，便于更新与回滚：

```
open/
├── README.md          ← 本文件（总览）
└── v1.0.0/            ← 1.0.0 版本
    ├── allowance-1.0.0.jar   ← 可直接使用的成品 jar
    ├── build.gradle / settings.gradle / gradle.properties
    └── src/                  ← 完整源码
        └── main/
            ├── java/com/allowance/...
            └── resources/    （neoforge.mods.toml / 语言文件 / pack.mcmeta）
```

## 从源码构建

环境要求：JDK 21、Gradle 8.x

```bash
cd v1.0.0
gradle build
# 产物位于 build/libs/allowance-1.0.0.jar
```

> 注意：Gradle 构建依赖 `maven.neoforged.net`。该站点在国内可能无法直连，
> `build.gradle` 中已配置阿里云 / BMCLAPI 镜像作为后备源；
> `local-repo/` 本地仓库方案请参考 `v1.0.0/BUILD.md`。
